# Archived SQLite migration history (inactive)

These directories are **historical artifacts** from the pre-PostgreSQL owner-ops schema.

They are **not** part of the active Prisma migrate path (`prisma/migrations/`).
Do **not** run them against Neon or any PostgreSQL database.
Do **not** move them back into `prisma/migrations/` without a separate authorization.

Active Production/local schema history starts at the PostgreSQL baseline under
`prisma/migrations/`.
