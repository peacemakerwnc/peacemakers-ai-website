# Process Improvement Standard

**ID:** `pm-os-process` · **Version:** `0.1.0`

## Current-state capture

Always record: trigger, inputs, outputs, actors, systems, steps, decisions, queues, handoffs, waits, approvals, exceptions, rework, escalation, termination.

Capture **documented** and **actual** process; record differences explicitly.

## Lean / waste

Consider: defects, overproduction, waiting, non-utilized talent, transportation, inventory/backlog, motion, extra processing — plus duplicate entry, reconciliation, avoidable approvals, status chasing, repeated transforms, unnecessary communication, manual copy between systems.

## Six Sigma / variation

Define defect, frequency, sources of variation, inputs, baseline availability. Use DMAIC where appropriate. Do not manufacture precision without data.

## Root cause

Prefer 5 Whys, cause-and-effect, process mapping, Pareto when data supports it, constraint/FMEA-style reasoning, evidence reconciliation. Every recommendation must name the root cause it addresses.

## External frameworks

Lean and Six Sigma are **references**, not replacements for Peacemakers methodology.
