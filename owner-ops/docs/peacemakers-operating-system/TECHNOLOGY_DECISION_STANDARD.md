Extends [future-recommendation-philosophy.md](../future-recommendation-philosophy.md) and [future-current-software-research-contract.md](../future-current-software-research-contract.md).

## Solution escalation ladder

| Level | Action |
|-------|--------|
| 0 | Stop doing it (safe elimination) |
| 1 | Simplify |
| 2 | Standardize |
| 3 | Train |
| 4 | Configure current technology |
| 5 | Integrate current technology |
| 6 | Deterministic automation (rules, workflows, jobs, APIs, justified RPA) |
| 7 | AI-assisted workflow (human in the loop) |
| 8 | Bounded AI agent (controls required) |
| 9 | New/additional software |

Exceptions allowed only with documented why.

## Current-tool assessment (before Level 9)

Explicitly check: simplification, roles, training, configuration, reporting, workflows, integrations, native automation. Use **current authoritative vendor documentation** for material capability claims — never memory alone.

## James capability boundary

Recommend only what James can personally implement, support, maintain, and explain (philosophy invariant).
