# Future Blueprint Generator — data contract (Phase 1.1 / Increment 4)

**Status:** Documented only. Do not implement generation in Phase 1.1.

## Authoritative inputs (allowed)

Only evidence that has passed owner review may feed generation:

- Accepted questionnaire evidence (submitted response + derived process graphs)
- Accepted transcript findings
- Accepted consultant findings
- Confirmed client decisions
- Resolved discrepancies (with rationale retained)
- Current software stack (as documented)
- Current processes (selected As-Is versions)
- Manual work descriptions
- Pain points
- Metrics (with confidence / data-source labels)
- Constraints and priorities
- Budget considerations (if client shared)
- Implementation capacity signals
- Approved external research (future phase)
- Explicit assumptions
- Open questions (must remain visible, not invented closed)
- James’s implementation capabilities (owner-maintained capability profile — future)

## Forbidden inputs

- Invitation tokens / auth secrets
- Rejected or duplicate findings (unless explicitly scoped for internal plan)
- Unresolved material conflicts treated as facts
- Cross-company data
- Fabricated ROI / savings
- Unapproved recommendations from prior runs
