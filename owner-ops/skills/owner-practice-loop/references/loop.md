# Practice loop

Run this whenever James asks to learn, apply, or improve one of the twelve practices, and again after a practice has been used on real work. Watching a video does not complete a turn.

The Peacemakers Operating System wins whenever a practice conflicts with it. Proposed work stays proposed until James approves it.

## Observe

1. Read the practice card in `practices.json`.
2. Read the matching module in `owner-ops/docs/learning/twelve-youtube-courses.md` if the card is too thin for the task.
3. Name the live task this practice will touch: a client stage, an internal chore, or a personal block (money, focus, life).
4. Write the boundary that applies: evidence class, approval gate, and what the practice must not do.

## Practice

1. Do the card's practice on that live task. One card per turn.
2. Keep client names, questionnaire bodies, tokens, and secrets out of the practice log.
3. Stop if the next step would contact a client, change a live system, send a proposal, or move money.

## Measure

Score the turn with one of these labels and a sentence of evidence:

- `used` — the practice changed the work in the way the card's measure describes
- `skipped` — the situation called for it and it was not done
- `unclear` — the card could not be followed as written
- `boundary` — following the card would have broken an operating-system rule, so the rule was kept
- `harm` — the practice made the work worse, less honest, or harder to support

Record the label in `owner-ops/docs/learning/practice-log.md`.

## Revise

1. `used` — leave the card. Pick the next module James has not practiced, or the oldest `skipped` card.
2. `unclear` — edit the practice sentence so the next run can follow it. Do not add a new framework.
3. `boundary` or `harm` — tighten `doNot` on that card before the practice is used again.
4. `skipped` — do the practice on the next real task of that kind. Do not add a tool to compensate.

Then start Observe again. The loop continues. A card is retired only when James says the practice is now a habit he can perform without the card.
